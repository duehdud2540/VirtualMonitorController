# VirtualMonitor — 프로그램 사용 안내

현재 소스 버전은 **0.2.0**입니다. 아래 2026-10-13 ZIP 설치 안내는 이전 배포본에 해당합니다. 새 소스의 구조·빌드·복구·검증은 [현재 아키텍처](ARCHITECTURE.md)를 참고하세요. 이전 ZIP은 이번 변경으로 갱신하지 않았습니다.

VirtualMonitor는 Windows에 설치된 **MttVDD 가상 모니터를 켜고 끄고, 그 화면을 별도 창에서 보여 주는 프로그램**입니다. 실제 모니터를 추가로 연결하지 않고 확장 바탕 화면을 만들 수 있습니다.

미리보기 창을 작게 줄이고 **항상 위 + 간결 모드**를 사용하면 다른 작업을 하면서 가상 화면을 확인할 수 있습니다.

개발 원리를 공부하려면 [프로젝트 학습 안내](README-STUDY.md)를 읽어 주세요.

## 1. 사용할 수 있는 환경

| 항목 | 현재 배포본 |
| --- | --- |
| 운영체제 | Windows 11 이상, Intel/AMD x64 |
| 관리자 권한 | 최초 설치와 앱 실행 시 필요 |
| .NET | 배포본에 .NET 10.0.12 포함 |
| 가상 디스플레이 드라이버 | MttVDD 11.30.4.434 포함 |
| Visual Studio·SDK·WDK | 일반 사용자는 설치할 필요 없음 |
| ARM64·Windows 10·macOS·Linux | 현재 배포 대상 아님 |

설치 프로그램은 별도 파일을 다운로드하지 않습니다. 다만 Windows의 인증서 검증이나 조직의 보안 정책 때문에 인터넷 연결이 필요하거나 설치가 거부될 수 있습니다.

## 2. 다른 PC에 설치하기

일반 사용자는 이 저장소의 **Releases**에서 실행용 ZIP이 제공되는지 먼저 확인하세요. GitHub의 **Code → Download ZIP**은 소스 코드이므로 압축을 풀어도 바로 실행할 수 없습니다. 실행용 배포가 아직 등록되지 않았다면 배포본 등록을 기다리거나 개발 환경에서 직접 빌드해야 합니다.

기존 배포 파일명은 `VirtualMonitor-Win11-x64-20261013-tray.zip`입니다. 이 파일은 2026-10-13 버전이며 현재 소스 0.2.0과 기능이 다를 수 있습니다. 배포 ZIP은 Git 소스에 포함하지 않으며, 이 문서 수정으로 새 배포본이 만들어지거나 업로드된 것은 아닙니다.

1. ZIP **전체를 압축 해제**합니다. ZIP 안에서 바로 실행하지 마세요.
2. 압축을 푼 폴더의 **Install.bat**을 실행합니다.
3. 관리자 권한 요청을 허용합니다.
4. SignPath Foundation 게시자 인증서 등록 안내가 나오면 내용을 확인합니다. 동의할 경우 `Y`를 입력합니다.
5. 설치 완료 후 **Run.bat** 또는 **App\VirtualMonitor.exe**를 실행합니다.
6. 재부팅 안내가 나온 경우 Windows를 재시작한 뒤 실행합니다.

앱 EXE만 따로 복사하지 말고 **App 폴더 전체**를 함께 보관하세요. 정상 설치 후에는 Install.bat을 매번 실행할 필요가 없습니다.

설치 과정은 드라이버를 등록하고, 기존 MttVDD 장치가 없을 때만 장치 하나를 생성합니다. 따라서 설치 직후 가상 화면이 추가될 수 있습니다. 기존 설정 파일은 덮어쓰지 않습니다.

게시자 인증서는 필요한 경우 확인을 거쳐 `TrustedPublisher`에 등록합니다. 루트 인증서 저장소, Windows 테스트 서명 모드, 보안 부팅 설정은 변경하지 않습니다.

### MttVDD는 별도로 설치해야 하나요?

**MttVDD 드라이버가 Windows에 설치되어 있어야 합니다.** VirtualMonitor는 설치된 가상 모니터를 제어하는 앱이며, 앱 실행만으로 드라이버가 설치되지는 않습니다.

- **드라이버가 포함된 실행용 ZIP을 받은 경우:** 위의 `Install.bat`이 드라이버 등록과 초기 설정을 처리하므로 MttVDD를 별도로 다운로드할 필요가 없습니다.
- **이미 MttVDD를 사용하는 경우:** 설치 프로그램은 기존 장치를 재사용합니다. 설치 후 장치 관리자 → 디스플레이 어댑터에서 MttVDD 장치의 오류 여부를 확인하세요. 이 앱은 MttVDD 어댑터 하나인 구성을 지원합니다.
- **드라이버가 없는 앱만 받은 경우:** [MttVDD 공식 프로젝트](https://github.com/VirtualDrivers/Virtual-Display-Driver)의 설치 안내에 따라 드라이버를 먼저 설치하세요. 이 프로젝트에 포함된 드라이버 버전은 `11.30.4.434`이며, 다른 버전의 호환성은 별도로 확인해야 합니다.

앱의 모니터 추가·삭제 기능은 `C:\VirtualDisplayDriver\vdd_settings.xml` 또는 `C:\IddSampleDriver\vdd_settings.xml`을 사용합니다. 포함된 설치 프로그램은 파일이 없을 때 초기 설정을 만들고, 기존 파일은 유지합니다. 별도 설치 후 설정 파일을 찾을 수 없다는 오류가 나오면 공식 드라이버 설정과 설치 경로를 확인하세요. 두 경로 모두에 파일이 있다면 모니터 개수와 앱이 기록한 식별자가 일치해야 합니다. 기존 설정을 임의로 덮어쓰지 마세요.

일반 사용자는 Visual Studio, Windows SDK, WDK를 설치할 필요가 없습니다. 위의 기존 실행용 ZIP에는 .NET이 포함되어 있습니다. 별도로 받은 앱이 .NET 설치를 요구한다면 **.NET 10 Windows Desktop Runtime x64**가 필요합니다.

### 처음 실행한 뒤 기본 설정

1. `App\VirtualMonitor.exe`를 실행하고 관리자 권한 요청을 허용합니다.
2. **새로 고침**을 누른 뒤 MttVDD 장치를 선택하고 **켜기**를 누릅니다.
3. **확장 모드 적용**을 누릅니다. Windows 설정 → 시스템 → 디스플레이에서도 다중 디스플레이가 **확장**으로 설정되었는지 확인합니다.
4. Windows 디스플레이 설정의 **식별**로 실제 모니터와 가상 모니터를 구분합니다. 실제 모니터를 주 디스플레이로 유지하고 가상 모니터의 위치를 옆으로 배치합니다.
5. 처음에는 가상 모니터를 **1920×1080, 60Hz**로 설정하는 것을 권장합니다. 해상도는 디스플레이 설정에서, 주사율은 고급 디스플레이에서 지원되는 값으로 선택합니다.
6. 앱에서 **화면 보기**를 누르고 미리보기 창은 실제 모니터에 둡니다.

현재 소스 0.2.0에서는 **가상 모니터 관리**에서 모니터를 추가·삭제하고 해상도와 주사율을 적용할 수 있습니다. 이전 배포본에 해당 메뉴가 없다면 Windows 디스플레이 설정을 사용하세요.

## 3. 기본 사용 순서

1. 메인 창에서 MttVDD 장치를 선택합니다.
2. **켜기**를 누릅니다. 이미 켜져 있으면 이 단계는 필요 없습니다.
3. 확장 바탕 화면이 나타나지 않으면 **확장 모드 적용**을 누릅니다.
4. **화면 보기**를 눌러 가상 화면을 엽니다.
5. 다른 프로그램의 창을 Windows의 가상 모니터 영역으로 이동시킵니다. 해당 창을 활성화한 상태에서 `Win + Shift + ←/→`로 모니터 간 이동을 시도할 수도 있습니다.
6. 사용을 마치고 가상 모니터도 없애려면 메인 창에서 **끄기**를 누릅니다.

**메인 창을 최소화하거나 X를 누르면 트레이로 숨겨집니다.** 가상 뷰는 독립 창이므로 함께 최소화되거나 닫히지 않습니다. 작업 표시줄 오른쪽의 숨겨진 아이콘(∧)에서 VirtualMonitor 아이콘을 찾을 수 있습니다.

트레이 아이콘을 더블클릭하면 메인 창이 다시 열립니다. 우클릭 메뉴에서 **메인 화면 열기 / 가상 화면 보기 / 종료**를 선택할 수 있습니다. 가상 뷰만 닫아도 트레이 앱은 유지됩니다.

**앱을 완전히 끝내려면 트레이 메뉴의 종료를 선택하세요.** 이때 열린 가상 뷰도 닫힙니다. 앱 종료와 가상 모니터 끄기는 별개이므로, 장치까지 끄려면 메인 창의 끄기를 먼저 누르세요. 장치 상태 변경 중에는 완료 후 종료를 다시 선택해야 합니다.

가상 모니터를 끄면 그 화면에 있던 창이 다른 화면으로 이동할 수 있습니다. 확장 모드 적용은 Windows 전체 디스플레이 배치에 영향을 줍니다.

## 4. 버튼과 보기 옵션

| 위치 / 기능 | 설명 |
| --- | --- |
| 메인 창 — 켜기 / 끄기 | 선택한 MttVDD 장치를 활성화 / 비활성화 |
| 메인 창 — 새로 고침 | 장치 상태와 활성 디스플레이 목록 다시 조회 |
| 메인 창 — 화면 보기 | 가상 화면 미리보기 열기 |
| 미리보기 — 화면 선택 | 활성 MTT 가상 화면 중 볼 화면 선택 |
| 원본 크기 (1:1) | 원본 픽셀 크기로 표시. 창보다 크면 스크롤 사용 |
| 1:1 체크 해제 | 화면 비율을 유지하며 창에 맞춰 표시 |
| 항상 위 | 다른 일반 창보다 앞에 미리보기 고정. 체크 해제로 복귀 |
| 간결 모드 | 상단 제목·버튼과 하단 상태·배율 영역을 얇게 표시 |
| 기본 모드 | 간결 모드에서 일반 화면으로 복귀 |
| 전체 화면 / F11 | 전체 화면 진입·복귀. 전체 화면에서는 Esc로도 복귀 |

간결 모드에서도 제목 영역을 끌어 창을 이동하고, 가장자리에서 크기를 조절할 수 있습니다. 최소화·최대화/복원·닫기 버튼도 남아 있습니다. 항상 위와 간결 모드는 각각 켜고 끌 수 있습니다.

미리보기 창은 **실제 모니터 쪽에 두는 것을 권장**합니다. 가상 모니터 안에 두면 자기 자신을 다시 캡처하는 화면이 보일 수 있습니다.

## 5. 해상도·화질·프레임

현재 소스에서는 **가상 모니터 관리 → 화면 모드 적용**에서 활성 모니터의 해상도와 주사율을 변경합니다. Windows 디스플레이 설정에서도 변경할 수 있습니다.

현재 미리보기는 Windows Graphics Capture를 이용해 원본 해상도로 캡처합니다. 예를 들어 가상 모니터가 1920×1080이면 캡처도 1920×1080입니다. 이전 버전의 960px 축소 제한은 없습니다.

작은 창에 1080p 화면 전체를 표시하면 글자가 작아지고 축소 때문에 흐려 보일 수 있습니다. 글자를 선명하게 확인하려면 **원본 크기 (1:1)**를 사용하세요. 배율 변경은 보기 크기만 바꾸며 가상 모니터 해상도 자체를 변경하지 않습니다.

갱신 목표는 **최대 60fps**입니다. 현재 기본 출력은 캡처와 같은 GPU 장치에서 실행하며 CPU 프레임 복사를 거치지 않습니다. 출력 오류 시 WPF 경로로 전환합니다. FPS는 제출 통계이며 모니터 주사율이나 실제 고유 표시 프레임 수와 다릅니다. 이전 버전의 약 39fps 측정값은 이번 구조의 성능 측정값이 아닙니다.

## 6. 현재 가능한 것과 없는 것

- Windows가 인식하는 가상 모니터 켜기·끄기, 보기 전용 미리보기, 커서 포함 캡처를 제공합니다.
- **미리보기 안에서 클릭하거나 타이핑해 가상 화면을 조작하는 기능은 없습니다.** 커서 표시와 입력 전달은 별개의 기능입니다.
- 소리 전달, 녹화, 원격 접속, 네트워크 화면 공유는 구현하지 않았습니다.
- 현재 소스의 관리 창에서 최대 16개 모니터를 추가·삭제하고 별칭을 저장할 수 있습니다. MttVDD 어댑터 하나인 구성을 지원합니다.
- 개별 모니터를 켜고 끌 수 있으며 마지막 활성 모니터를 끄면 어댑터도 끕니다. 추가·삭제 등 구성 변경 중에는 미리보기를 일시 정지합니다.
- 보호된 영상이나 보안 화면은 캡처되지 않을 수 있습니다. Windows가 캡처 중인 화면의 테두리를 표시할 수도 있습니다.
- 사용자 정의 EDID로 MTT 식별자가 바뀐 화면은 미리보기 목록에 나타나지 않을 수 있습니다.
- 항상 위·간결 모드 같은 보기 설정을 다음 실행까지 저장하는 기능은 없습니다.

## 7. 문제가 생기면

| 증상 | 확인할 내용 |
| --- | --- |
| MttVDD 장치가 없음 | 최초 Install.bat 설치 결과 확인 |
| 켜졌는데 미리보기가 없음 | 확장 모드 적용, Windows 디스플레이 설정 확인 |
| 앱 종료 후에도 모니터가 남음 | 정상 동작. 종료 전에 메인 창에서 끄기 선택 |
| 글자가 흐림 | 가상 화면 해상도 확인 후 1:1 보기 선택 |
| 클릭이 가상 화면에 전달되지 않음 | 현재 미리보기는 보기 전용 |
| 장치 제어 접근 거부 | 앱의 관리자 권한 요청을 허용했는지 확인 |
| 서명·설치 오류 | 오류 메시지와 장치 관리자 문제 코드 확인. 보안 설정을 임의로 끄지 않기 |
| DLL 또는 실행 구성 요소 누락 | ZIP 전체를 새 폴더에 압축 해제했는지 확인 |

예전 바탕 화면의 1~4번 개발용 BAT 대신 **이번 배포 ZIP의 Install.bat**을 사용하세요. 특히 옛 3번 BAT는 테스트 서명 설정을 바꾸며, 옛 4번 BAT는 장치를 중복 생성할 수 있습니다.

## 8. 검증 상태와 출처
