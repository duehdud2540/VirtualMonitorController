# VirtualMonitor

**물리 모니터를 추가하지 않고 Windows에 가상 화면을 만들고, 그 화면을 별도의 창으로 확인할 수 있는 데스크톱 앱입니다.**

가상 모니터를 켜고 끄거나 여러 개 추가할 수 있으며, 각 모니터의 이름·해상도·주사율을 관리할 수 있습니다. 가상 화면에 배치한 프로그램은 실시간 미리보기로 확인할 수 있습니다.

## 주요 기능

- **모니터 관리:** 최대 16개의 가상 모니터 추가, 개별 켜기·끄기 및 삭제
- **화면 설정:** 확장 모드 적용, 지원 해상도·주사율 선택
- **이름 지정:** 모니터별로 알아보기 쉬운 별칭 저장
- **실시간 미리보기:** 전체 화면, 항상 위, 간결 모드, 원본 크기 보기
- **트레이 실행:** 메인 창을 숨겨도 미리보기 유지
- **설정 보호:** 설정 백업, 변경 실패 시 복구 시도 및 오류 로그 기록

## 실행 환경

| 항목 | 요구 사항 |
| --- | --- |
| 운영체제 | Windows 11 이상 |
| PC 종류 | Intel/AMD x64 PC (ARM64 미지원) |
| .NET | **.NET 10 Desktop Runtime (x64)** — 직접 설치 |
| 가상 디스플레이 드라이버 | **MttVDD** — 배포본의 `Install.bat`으로 설치 |
| 권한 | 드라이버 설치 및 앱 실행 시 관리자 권한 필요 |

일반 사용자는 Visual Studio, Windows SDK, WDK를 설치할 필요가 없습니다. 현재 배포본은 별도의 Visual C++ 재배포 패키지도 요구하지 않습니다.

## 설치 순서

**배포 ZIP 압축 해제 → .NET 설치 → Install.bat 실행 → Run.bat 실행** 순서로 진행하세요.

### 1. 배포 파일 다운로드 및 압축 해제

GitHub에 제공된 실행용 배포 ZIP을 내려받아 **전체 압축을 해제**합니다. 저장소 파일을 내려받은 경우에는 최상단의 `배포용퍼블리쉬` 폴더를 사용하세요.

실행에 사용하는 폴더에는 다음 파일이 함께 있어야 합니다.

```text
배포용퍼블리쉬/
├── App/                    # 앱 실행 파일과 필요한 DLL
├── Driver/                 # MttVDD 드라이버 설치 파일
├── Install.bat             # 드라이버 설치 시작
├── Install.ps1             # 실제 설치 처리
├── Run.bat                 # 실행 환경 확인 후 앱 시작
├── Run.ps1                 # 실행 조건 검사 및 앱 실행
├── 사용방법.md
├── MttVDD-LICENSE.txt
└── package-manifest.json
```

**BAT 파일이나 EXE 파일만 따로 옮기지 마세요.** `App`, `Driver` 폴더와 `.ps1` 파일을 함께 유지해야 합니다. ZIP 안에서 바로 실행하지 말고 먼저 압축을 해제하세요.

### 2. .NET 10 Desktop Runtime 설치

[Microsoft 공식 .NET 10 다운로드 페이지](https://dotnet.microsoft.com/download/dotnet/10.0)에서 **.NET Desktop Runtime → Windows → x64**를 선택해 설치합니다.

- .NET 런타임은 배포본에 포함되어 있지 않습니다.
- `Install.bat`과 `Run.bat`은 .NET을 자동으로 다운로드하거나 설치하지 않습니다.
- **ASP.NET Core Runtime 또는 일반 .NET Runtime만으로는 부족합니다.** WPF 앱 실행에 필요한 **Desktop Runtime**을 설치해야 합니다.
- 이미 .NET 10 Desktop Runtime(x64)이 설치되어 있다면 이 단계는 건너뛰어도 됩니다.

### 3. MttVDD 드라이버 설치

배포 폴더의 **`Install.bat`**을 실행합니다.

1. Windows 관리자 권한 요청을 승인합니다.
2. 게시자 인증서 등록 안내가 나오면 내용을 확인하고, 진행하려면 `Y`를 입력합니다.
3. 설치 완료 메시지를 확인합니다.
4. 재부팅 안내가 나오면 Windows를 재시작합니다.

**MttVDD는 가상 모니터를 만드는 데 필요한 드라이버이므로 Windows에 설치해야 합니다.** 드라이버 파일은 배포본의 `Driver` 폴더에 포함되어 있어 별도로 다운로드할 필요는 없습니다. `Install.bat`이 해당 파일을 이용해 드라이버를 설치하고 가상 장치를 준비합니다.

기존 MttVDD 장치가 있으면 재사용하며 기존 설정 파일은 유지합니다. 필요한 경우 SignPath Foundation 인증서를 Windows의 **신뢰할 수 있는 게시자** 저장소에 등록합니다. 설치 스크립트는 테스트 서명 모드와 보안 부팅 설정을 변경하지 않습니다.

### 4. 앱 실행

배포 폴더의 **`Run.bat`**을 실행하고 관리자 권한 요청을 승인합니다.

`Run.bat`은 필요한 앱 파일, Windows 구성 요소 및 .NET Desktop Runtime을 확인한 뒤 앱을 실행합니다. 이후 사용할 때는 드라이버를 매번 설치할 필요 없이 `Run.bat`으로 시작하면 됩니다.

## 사용 방법

### 가상 모니터 켜기

1. 메인 화면의 선택 목록에서 사용할 가상 모니터를 고릅니다.
2. **켜기**를 누릅니다.
3. 현재 활성 디스플레이 목록에서 상태를 확인합니다.
4. 화면이 활성화되지 않으면 **확장 모드 적용**을 누릅니다.

설정된 모니터가 없다면 **가상 모니터 관리 → 모니터 1개 추가**를 먼저 사용하세요. 목록을 다시 불러오려면 **새로 고침**을 누릅니다.

### 가상 화면에 프로그램 배치하기

Windows 디스플레이 설정에서 실제 모니터와 가상 모니터의 배치를 확인합니다. 사용할 프로그램의 창을 가상 화면 쪽으로 이동하세요. 현재 선택한 프로그램 창은 `Win + Shift + ←/→` 단축키로 다른 모니터에 이동할 수도 있습니다.

메인 화면에서 켜진 가상 모니터를 선택하고 **화면 보기**를 누르면 해당 화면을 미리보기 창에서 확인할 수 있습니다.

### 미리보기 사용하기

| 조작 | 동작 |
| --- | --- |
| 전체 화면 버튼 / `F11` | 전체 화면 전환 |
| `Esc` | 전체 화면 해제 |
| 항상 위 | 미리보기 창을 다른 일반 창보다 앞에 유지 |
| 간결 모드 / 기본 모드 | 창의 표시 방식 전환 |
| 원본 크기 (1:1) | 원본 픽셀 크기로 표시 |

같은 모니터의 미리보기는 중복으로 열리지 않습니다. 실제 갱신 속도는 가상 화면의 변화와 PC 환경에 따라 달라집니다.

### 모니터 추가·삭제 및 설정 변경

메인 화면에서 **가상 모니터 관리**를 엽니다.

| 버튼 | 사용 방법 |
| --- | --- |
| 모니터 1개 추가 | 가상 모니터를 하나 추가합니다. 최대 16개까지 지원합니다. |
| 선택 모니터 삭제 | 목록에서 선택한 가상 모니터를 제거합니다. |
| 모두 삭제 | 설정된 가상 모니터를 모두 제거합니다. 실제 모니터는 삭제하지 않습니다. |
| 이름 저장 | 이름 입력란을 수정한 뒤 저장합니다. 앱에서 표시할 별칭이며 Windows 장치명은 유지됩니다. |
| 화면 모드 적용 | 켜진 모니터를 선택하고, 목록에서 지원 해상도·주사율을 골라 적용합니다. |

모니터 추가·삭제는 MttVDD 어댑터가 하나 설치된 구성을 지원합니다. 개수를 변경할 때 드라이버가 재시작될 수 있으며, 모니터를 끄거나 구성을 바꾸면 Windows가 열린 창의 위치를 조정할 수 있습니다.

### 모니터 끄기 및 앱 종료

- **모니터 끄기:** 메인 화면에서 해당 모니터를 선택하고 **끄기**를 누릅니다. **켜기**를 누르면 다시 사용할 수 있습니다.
- **메인 창 숨기기:** 최소화하거나 `X`를 누르면 트레이로 숨겨집니다. 열린 미리보기는 유지됩니다.
- **메인 창 다시 열기:** 작업 표시줄 알림 영역의 트레이 아이콘을 더블클릭합니다.
- **앱 완전히 종료하기:** **트레이 아이콘 우클릭 → 종료**를 선택합니다.

**앱 종료와 가상 모니터 끄기는 별도 동작입니다.** 가상 모니터까지 끄려면 앱 종료 전에 **끄기**를 사용하세요. 트레이 아이콘이 보이지 않으면 알림 영역의 숨겨진 아이콘 목록을 확인하세요.

## 자주 묻는 질문

### MttVDD를 별도로 설치해야 하나요?

Windows에 설치하는 과정은 필요하지만, 따로 다운로드할 필요는 없습니다. 배포본의 **`Install.bat`이 포함된 MttVDD 드라이버를 설치**합니다. 파일을 압축 해제하거나 앱을 실행하는 것만으로는 드라이버가 설치되지 않습니다.

### DLL을 따로 설치하거나 복사해야 하나요?

앱에 필요한 캡처·렌더링 DLL은 `App` 폴더에 포함되어 있습니다. 직접 시스템 폴더에 복사하거나 `regsvr32`로 등록할 필요가 없습니다. DirectX 관련 DLL과 Universal CRT는 Windows 11 기본 구성 요소를 사용합니다.

### 개발 도구 설치 BAT도 실행해야 하나요?

필요하지 않습니다. 저장소의 `setup` 폴더에 있는 SDK·WDK 설치 및 테스트 드라이버 스크립트는 초기 개발용입니다. 일반 사용자는 **배포 폴더의 `Install.bat`과 `Run.bat`**을 사용하세요.

## 문제 해결

| 증상 | 확인할 내용 |
| --- | --- |
| .NET 런타임이 없다는 오류 | .NET 10 **Desktop Runtime x64** 설치 여부 확인 |
| 앱 파일이 없다는 오류 | ZIP 전체를 압축 해제했는지, `App`과 `.ps1` 파일이 함께 있는지 확인 |
| 설치된 MttVDD 장치가 없다고 표시됨 | `Install.bat` 설치 결과 및 Windows 장치 관리자 확인 |
| 설정된 가상 모니터가 없음 | 가상 모니터 관리에서 모니터 추가 |
| 켰지만 화면이 활성화되지 않음 | 확장 모드 적용 후 새로 고침, Windows 디스플레이 설정 확인 |
| DirectX DLL이 없다는 오류 | Windows 업데이트 또는 시스템 복구로 기본 구성 요소 확인 |
| 창을 닫아도 앱이 실행 중임 | 트레이 아이콘 우클릭 → 종료 |
| 구성 복구 안내가 표시됨 | 현재 모니터 상태와 아래 복구 기록·로그 확인 |

미리보기 출력에 문제가 있으면 배포 폴더에서 PowerShell을 열어 다음 명령으로 WPF 출력 방식을 사용해 볼 수 있습니다.

```powershell
.\App\VirtualMonitor.exe --wpf-preview
```

### 설정 및 로그 위치

| 위치 | 내용 |
| --- | --- |
| `%LOCALAPPDATA%\VirtualMonitor\Logs` | 날짜별 동작·오류 로그 |
| `%LOCALAPPDATA%\VirtualMonitor\Recovery` | 구성 변경 및 복구 기록 |
| `%LOCALAPPDATA%\VirtualMonitor\monitor-names.json` | 모니터 별칭 |
| `C:\VirtualDisplayDriver\vdd_settings.xml` | 드라이버 설정 |
| `C:\IddSampleDriver\vdd_settings.xml` | 함께 사용하는 드라이버 설정 경로 |

구성 변경 중 오류가 발생하면 이전 상태로 복구를 시도합니다. 복구 미완료 안내가 표시되면 현재 모니터 구성을 확인하세요. 두 XML 파일이 모두 존재하는 경우 모니터 개수와 식별 정보가 일치해야 합니다.

문제를 제보할 때는 Windows 버전, 수행한 작업, 표시된 오류 메시지와 해당 시간대의 로그를 함께 남겨 주세요.

## 개발 참고

앱은 **C# / .NET 10 / WPF**로 작성되었으며, **C++ / Windows Graphics Capture / Direct3D 11**을 이용해 가상 화면을 캡처하고 표시합니다.

소스를 직접 빌드하려면 .NET 10 SDK, Visual Studio 또는 Build Tools의 **C++를 사용한 데스크톱 개발** 워크로드, Windows SDK가 필요합니다.

```powershell
# 프로젝트 루트에서 실행
dotnet restore .\VirtualMonitor.csproj
.\build.ps1 -Configuration Release

# 빌드 후 회귀 진단까지 실행하려면
.\build.ps1 -Configuration Release -Verify
```

빌드 결과는 `bin/Release/net10.0-windows`에 생성됩니다. 네이티브 DLL은 빌드 과정에서 자동 생성되며, MttVDD 드라이버 설치는 별도로 진행해야 합니다. `-Verify`는 실제 디스플레이 구성을 변경하지 않는 아키텍처 진단을 실행합니다.
